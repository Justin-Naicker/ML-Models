# Exam Score Prediction

A machine learning web application that predicts student exam performance based on academic and personal factors. The project uses supervised learning models built with **scikit-learn** and provides an interactive interface through **Streamlit** for real-time predictions.

## Features

- Predicts student exam scores from user-provided inputs
- Interactive web interface built with Streamlit
- Data preprocessing and feature engineering
- Model serialization using Pickle (.pkl)
- Hyperparameter tuning and model evaluation
- Real-time inference using a trained machine learning model

## Tech Stack

- Python
- Streamlit
- scikit-learn
- Pandas
- NumPy
- Pickle

## Machine Learning Pipeline

1. Load and preprocess the dataset
2. Perform feature engineering and data cleaning
3. Train multiple machine learning models
4. Tune hyperparameters to improve performance
5. Serialize the best-performing model
6. Deploy the model through a Streamlit application
